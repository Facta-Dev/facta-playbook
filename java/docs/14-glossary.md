# Glossary

- **Slice**: one capability with domain/application/adapters/presentation.
- **Port**: the interface the consumer declares; the adapter implements it.
- **Use case**: the transaction boundary and the rule.
- **Outbox**: a table written in the same transaction as the domain row.
- **RLS**: PostgreSQL row-level security, the tenant second line.
- **DTO**: the API record; never an entity.
- **Envelope**: the shared error shape.

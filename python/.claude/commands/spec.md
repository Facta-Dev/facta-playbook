## Delegate

Delegate to the **spec** skill. Activate when the request is to turn an idea or bug report for <app> into a filed GitHub issue — interrogate scope and acceptance criteria, fail-closed redaction-scan the full draft, dedupe against open issues, then file it with `gh issue create`.
